# NOVA Shopping

**Discover better. Shop smarter.**

NOVA is an ambitious marketplace concept focused on thoughtful product discovery, transparent comparisons, and a customer-first shopping experience.

## Current build

This repository currently contains a responsive, browser-based storefront prototype:
- Product discovery with search, categories, filters, and sorting
- Product cards with ratings, sale pricing, and demo catalog data
- Persistent shopping cart and saved items using browser local storage
- Cart quantity controls and subtotal calculation
- Responsive desktop and mobile layouts
- Account and checkout placeholders that clearly disclose they are not connected

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Important prototype limitations

This is a front-end demo, not a production Amazon replacement. Product data is sample data. Authentication, inventory, real seller accounts, order management, shipping/tax calculation, payment processing, customer support, and backend APIs are not connected. Do not enter real payment information. A production launch needs a secure backend, database, payment provider, shipping integrations, privacy/security review, and operational support.

## Product direction

Planned platform capabilities:
1. Customer accounts, addresses, order history, returns, and wishlists
2. Seller onboarding, storefronts, catalog management, and payouts
3. Secure checkout, taxes, shipping rates, tracking, and refunds
4. Reviews, Q&A, verified purchases, and product comparison
5. Personalized discovery, price-drop alerts, and smarter search
6. Admin tools, moderation, fraud prevention, analytics, and customer support

NOVA should build on familiar marketplace fundamentals while differentiating through transparent comparisons, useful recommendations, accessible design, and clear customer controls.
